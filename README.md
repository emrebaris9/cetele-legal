# cetele-legal

Çetele'nin herkese açık sayfaları (GitHub Pages: https://emrebaris9.github.io/cetele-legal/).

- `index.html` — tanıtım sayfası
- `kosullar.html` / `gizlilik.html` — Türkçe Kullanım Koşulları ve Gizlilik Politikası
- `terms.html` / `privacy.html` — İngilizce karşılıkları (uygulama telefon dili İngilizce ise bunları açar)

Ürün kaynağı: `cetele` deposundaki `PROJECT_SPEC.md` §34 (Çetele Pro). İngilizce metinlerin
kaynağı `cetele/docs/legal`; buradaki sürüm aynı içeriğin site şablonuna oturtulmuş hâlidir.
